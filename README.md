## 🎟️ Registration Protocol & Marvel Quantum Ticket

- **Strict University Verification**:
  - Validates full name, enrollment number (e.g. `E22CSEU0001`), branch, and year.
  - **Strict Security Email Validation**: Only accepts official university email addresses ending in `@bennett.edu.in`. Rejects all other domains with a real-time glowing red warning prompt.
- **Dynamic Ticket Materialization**:
  - Unique Ticket ID generation (e.g. `AVN-2026-X89KJ`).
  - Cryptographic QR code rendered client-side containing verified attendee metadata.
  - Authentic comic-book / boarding-pass hybrid ticket with:
    - Rainbow holographic foil shifting border.
    - Perforated tear-off stub with authentic notches.
    - Security barcode, serial numbers, and S.H.I.E.L.D. Earth-616 seal.
- **Download & Print Capabilities**:
  - **Download Ticket (PNG)**: Renders a high-resolution 2x canvas snapshot of the ticket.
  - **Print Ticket**: Strips all navigation, background layers, and controls via `@media print` to print a pristine physical pass.
  - **Browser Vault**: Stores passes locally in `localStorage` with a modal viewer.
  - **Marvel Confetti Burst**: Multi-cannon confetti blast in Marvel Red, Gold, Cyan, and Purple upon registration.
